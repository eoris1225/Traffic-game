# FLOW LAB — 마비된 도심을 풀어라

강을 낀 작은 동네. 바깥 도로는 멀쩡한데 이 구역만 출근 시간마다 멈춰 섭니다. 잘못 놓인 도로를 찾아 고치는 도로 설계 퍼즐입니다.
죽는(Game Over) 구조 없이 **관찰 → 고치기 → 실행**으로 진행합니다.
고칠 때는 위에서 내려다보는 흑백 도시에서 도로·시설·구역 안 건물만 컬러로 보이고, 실행하면 화면이 컬러로 바뀌며 대각선 시점으로 차량 흐름을 보여 줍니다.

## 바로 해 보기 (GitHub Pages)

빌드가 없는 정적 사이트라서 저장소 루트를 그대로 Pages 로 내보내면 됩니다.

1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: 이 코드가 있는 브랜치 / 폴더 `/ (root)` → **Save**
4. 1~2분 뒤 `https://eoris1225.github.io/Traffic-game/` 에서 열립니다.

비공개 저장소는 GitHub 유료 플랜에서만 Pages 를 쓸 수 있습니다. 무료 플랜이라면 저장소를 공개로 바꿔야 합니다.
루트의 `.nojekyll` 은 Pages 가 파일을 가공하지 않고 그대로 내보내게 하는 빈 파일입니다.

## 실행

`index.html` 을 브라우저로 열면 됩니다(설치·빌드 없음). PC와 모바일(터치) 모두 됩니다.
3D 화면은 `vendor/three.min.js`(MIT)를 쓰며, WebGL 이 안 되는 환경에서는 2D 지도로 대체됩니다.

## 플레이

1. **관찰** — 어디가 막히는지 봅니다. 도로가 붉게 물들수록 심하게 막힌 곳입니다.
2. **고치기** — 아래 트레이에서 도구 아이콘을 누르면 이름·가격·설명이 뜨고, 칸을 누르면 설치됩니다. 같은 도구로 다시 누르면 전액 환불됩니다. 풀밭·텃밭·주차장 같은 빈 터에는 길을 낼 수 있고, 집·건물·공사 구역은 건드릴 수 없습니다. 공원은 지하차도로만, 강은 다리로만 지납니다. 총예산 $3,500.
3. **실행** — 같은 차량들이 다시 달립니다.

## Stage 1 — 도심 지름길의 역설 (브라에스 역설)

주택가에서 회사로 가는 길이 두 갈래입니다. 위쪽 길은 서쪽 횡단보도를, 아래쪽 길은 동쪽 횡단보도를 한 번씩 지납니다.
가운데 지름길은 두 길을 이어 주는데, 이 길이 있으면 거의 모든 차가 "횡단보도 → 지름길 → 횡단보도"로 몰려 병목 두 곳을 전부 지나게 됩니다.

공식 시드(1225) 측정값:

| 설계 | 예산 | 평균 이동시간 | 사고 | 도착 |
|---|---|---|---|---|
| 고치기 전 | $0 | 32.0초 | 1건 | 123/139 |
| 지름길에 통행 차단 1개 (★) | $100 | 23.5초 | 1건 | 134/139 |
| 지름길 양끝 회전교차로 + 육교 2개 (★★) | $1,800 | 22.3초 | 0건 | 139/139 |
| 지름길을 버스 전용으로 + 육교 2개 (보라색 ★) | $1,100 | 15.9초 | 0건 | 139/139 |

도로를 하나 **막았는데** 전체가 빨라집니다. 다른 시드에서도 같은 방향입니다(시드 7: 29.5 → 20.2초, 시드 99: 27.8 → 18.2초, 6개 시드 평균 약 −25%).
수치는 시드에 따라 달라지며, 화면의 "예상" 값은 일부러 다른 시드로 계산한 추정치입니다.

## 엔진 (`js/sim.js`)

- **길 찾기**: A*, 간선 비용은 BPR 함수 `t = t₀·(1 + α·(v/c)^β)` (α=0.15, β=4). 차량은 약 3초마다 경로를 다시 찾습니다.
- **앞차 따라가기**: `v* = v_max·max(0, (Δx − d_min)/d_safe)` 에 제동 한계와 반응 지연을 더한 모델.
- **운전자**: 일반 70% / 과속 15% / 초보 15% + 버스(승객 20명). 차량마다 `(v₀, T, a, b)` 가 정규분포 난수.
- **사고**: 차체가 실제로 겹치면 사고. 그 칸은 10초간 통행 불가, 사고 차량은 30초 페널티.
- **평가**: `T̄ = Σ Wᵢ·tᵢ / Σ Wᵢ` (승용차 W=1, 버스 W=20). 도착하지 못한 차량도 포함합니다.
- 엔진은 칸의 속성에 따른 국소 규칙만 계산하며 특정 좌표를 채점하지 않습니다. DOM 의존성이 없어 Node 에서도 돌아갑니다.

```js
const F = require('./js/sim.js');
const tiles = F.parseStage(F.STAGE1);
tiles[4 * F.W + 5].barricade = true;          // 지름길 (5,4) 차단
console.log(new F.Sim(tiles, { seed: 1225 }).run());
```

## 동네

- 격자 안은 큰 건물 몇 동, 주택(단독·연립·차고 딸린 집), 공원, 그리고 길을 낼 수 있는 빈 터로 이루어집니다. 빈 터는 풀밭·꽃밭·텃밭·자갈 주차장으로 보이고, 길을 내면 사라집니다.
- 강을 건너는 기존 도로는 석조 교대에 주철 아치와 난간이 달린 다리입니다. 강 위에 새 길을 내려면 다리 도구를 써야 합니다.
- 육교는 상판·계단·난간이 하나로 이어진 구조물이고, 사람들이 실제로 계단을 올라 건너갑니다.
- 보도에는 사람들이 오가고, 몇몇은 강아지를 산책시킵니다. 강에는 배가 지나갑니다. 모두 배경이며 교통 시뮬레이션에는 영향을 주지 않습니다.
- 격자 밖은 저주파 노이즈로 녹지 / 주택가 / 상가를 나눠 배치합니다. 움직이지 않는 것은 재질별로 한 덩어리로 합쳐 그립니다.

## 디자인

도로 표지판에서 가져온 시각 언어를 씁니다: 차선 점선이 들어간 아스팔트색 상단 바, 초록 방향 표지판 모양의 예산판. 상자는 예산판·도구 트레이·상태 띠·창에만 쓰고 나머지는 글자와 아이콘만 둡니다. 글꼴은 Wanted Sans 하나이고 아이콘은 이모지 없이 직접 그린 SVG입니다.

## 알려진 한계

- 신호등, 가변 차선, 방지턱은 단독으로는 효과가 작습니다.
- 교차로를 바짝 붙여 지으면 드물게 정체가 오래 풀리지 않을 수 있습니다.
- Stage 2~5 는 잠금 표시만 있습니다.
- 격자 바깥의 동네와 그 도로를 달리는 차, 보행자, 배는 배경이며 시뮬레이션에 포함되지 않습니다.
- 보행자는 곧게 뻗은 보도 구간만 오갑니다(교차로를 건너지 않습니다).

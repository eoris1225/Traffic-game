# FLOW LAB — 꽉 막힌 도로를 풀어라

죽는(Game Over) 구조 없이 **관찰 → 고치기 → 실행**으로 진행하는 도로 설계 퍼즐입니다.
고칠 때는 흑백 배경의 탑뷰에서 도로·시설·건물만 컬러로 보이고, 실행하면 화면이 컬러로 바뀌며 대각선 시점의 로우폴리 3D로 차량 흐름을 보여 줍니다.

## 실행

`index.html` 을 브라우저로 열면 됩니다(설치·빌드 없음). 3D 화면은 `vendor/three.min.js`(MIT)를 쓰며, WebGL 이 안 되는 환경에서는 2D 지도로 대체됩니다.

## 플레이

1. **관찰** — 고치기 전 도로에서 어디가 막히는지 봅니다. 도로가 붉게 물들수록 심하게 막힌 곳입니다.
2. **고치기** — 총예산 $3,500 안에서 15가지 도구를 아무 칸에나 설치합니다. 정답 자리는 없습니다.
3. **실행** — 같은 차량들이 다시 달립니다. 평균 이동시간 24초 이하·사고 1건 이하면 성공(★), 21초 이하·무사고 ★★, 17초 이하·무사고 ★★★.

화면에는 교통 상황 신호등(원활/서행/정체), 평균 이동시간, 사고, 도착 대수만 보입니다. 그래프·실험 기록·모델 수식은 **수치 확인**에 따로 있습니다.

| 조작 | 동작 |
|---|---|
| 칸 클릭·드래그 | 선택한 도구 설치 (같은 도구로 다시 누르면 회수) |
| `Space` | 실행 / 정지 |
| `Ctrl+Z` | 되돌리기 |
| 실행 중 드래그 / 휠 | 시점 회전 / 확대 |
| 실행 중 차량 클릭 | 그 차량이 어디로 가는지 표시 |

차 위 말풍선: `?` 초보 운전자가 머뭇거림 · `!` 급정거 · `···` 오래 갇힘 · 카메라 그림은 단속에 걸려 감속

## Stage 1 — 도심 지름길의 역설 (브라에스 역설)

주택가에서 회사로 가는 길이 두 갈래입니다. 위쪽 길은 서쪽 횡단보도를, 아래쪽 길은 동쪽 횡단보도를 한 번씩 지납니다.
가운데 지름길은 두 길을 이어 주는데, 이 길이 있으면 거의 모든 차가 "횡단보도 → 지름길 → 횡단보도"로 몰려 병목 두 곳을 전부 지나게 됩니다.

공식 시드(1225) 측정값:

| 설계 | 예산 | 평균 이동시간 | 사고 | 도착 |
|---|---|---|---|---|
| 고치기 전 | $0 | 32.0초 | 1건 | 123/139 |
| 지름길에 통행 차단 1개 | $100 | 23.5초 | 1건 | 134/139 |
| 지름길을 버스 전용으로 + 육교 2개 | $1,100 | 15.9초 | 0건 | 139/139 |
| 지름길 양끝 회전교차로 + 육교 2개 | $1,800 | 22.3초 | 0건 | 139/139 |

도로를 하나 **막았는데** 전체가 빨라집니다. 다른 시드에서도 같은 방향입니다(시드 7: 29.5 → 20.2초, 시드 99: 27.8 → 18.2초, 6개 시드 평균 약 −25%).
수치는 시드에 따라 달라지며, 화면의 "예상" 값은 일부러 다른 시드로 계산한 추정치입니다.

## 엔진 (`js/sim.js`)

- **길 찾기**: A*, 간선 비용은 BPR 함수 `t = t₀·(1 + α·(v/c)^β)` (α=0.15, β=4). 차량은 약 3초마다 경로를 다시 찾습니다.
- **앞차 따라가기**: `v* = v_max·max(0, (Δx − d_min)/d_safe)` 에 제동 한계와 반응 지연을 더한 모델.
- **운전자**: 일반 70% / 과속 15% / 초보 15% + 버스(승객 20명). 차량마다 `(v₀, T, a, b)` 가 정규분포 난수.
- **사고**: 차체가 실제로 겹치면 사고. 그 칸은 10초간 통행 불가, 사고 차량은 30초 페널티.
- **평가**: `T̄ = Σ Wᵢ·tᵢ / Σ Wᵢ` (승용차 W=1, 버스 W=20). 도착하지 못한 차량도 포함합니다.
- 엔진은 칸의 속성에 따른 국소 규칙만 계산하며 특정 좌표를 채점하지 않습니다. DOM 의존성이 없어 Node 에서도 돌아갑니다.

```js
const F = require('./js/sim.js');
const tiles = F.parseStage(F.STAGE1);
tiles[4 * F.W + 5].barricade = true;          // 지름길 (5,4) 차단
console.log(new F.Sim(tiles, { seed: 1225 }).run());
```

## 디자인

도로 표지판에서 가져온 시각 언어를 씁니다: 아스팔트색 바와 차선 점선, 초록 방향 표지판 모양의 예산판, 크림색 표지판 카드, 눌리는 키 모양 버튼. 글꼴은 Wanted Sans 하나로 통일했고 아이콘은 이모지 대신 직접 그린 SVG 그림 문자입니다.

## 알려진 한계

- 신호등, 가변 차선, 방지턱은 단독으로는 효과가 작습니다.
- 교차로를 바짝 붙여 지으면 드물게 정체가 오래 풀리지 않을 수 있습니다.
- Stage 2~5 는 잠금 표시만 있습니다.
- 터치(모바일) 조작은 지원하지 않습니다.

# FLOW LAB 대본 작성 가이드

이 문서에는 대사가 없습니다. 게임 안의 **글자가 들어가는 자리마다** 어디에 뜨는지, 누가 말하는지, 그 글이 해야 할 일, 분량만 적었습니다.
이걸 보고 대사를 쓰신 뒤 `js/script.js` 의 같은 이름(키) 자리에 넣으면 게임에 그대로 반영됩니다.

- **키** — `js/script.js` 안의 이름입니다. 예: `tutorial.found` 는 `tutorial: { found: '…' }` 자리.
- **분량** — 한국어 글자 수(띄어쓰기 포함) 기준입니다. 범위 안이면 폰에서도 말풍선이 넘치지 않습니다.
- **버튼 그림** — 대사 안에 `{play}` 처럼 쓰면 실제 버튼 그림으로 바뀝니다. 그림 하나는 글자 약 2자 폭입니다. 목록은 `js/script.js` 맨 위에 있습니다.
- **추천 작업 순서** — 영어로 먼저 쓰고 한국어로 옮기면 "번역된 영국 인디게임" 결이 잘 나옵니다. 편지(`story.mail`)는 이미 `en`/`ko` 두 칸이 있습니다.

---

## 1. 세계와 톤

- **배경** — 이름 없는 작은 지방 도시의 도로과. 올해 말 시청의 **부서 폐지 심사**를 받는다. 시골·항구·도시·산 네 구역의 출근길을 심사 전까지 고쳐 놓아야 부서가 살아남는다.
- **플레이어** — 새로 온 "관리자". 올해 들어 네 번째. 대사는 없다. 모두가 존댓말로 대한다.
- **톤** — 담담한 관료 유머 + 은근한 다정함. 큰 사건 없이 작은 일상이 조금씩 나아지는 이야기. 웃음은 과장이 아니라 **한 박자 늦게 덧붙이는 말**, **사실을 너무 정직하게 말하는 것**에서 나온다.
- **번역투의 결** — 영어 원문이 있는 것처럼: 문장이 짧고 정확하다. 주어를 생략하지 않을 때가 많다. "~하는 것입니다", "그렇더라도." 같은 단문 마무리. 의성어·유행어·밈·이모지는 쓰지 않는다.
- **피할 것** — 인터넷 말투("ㅋㅋ", "레전드"), 교훈을 대놓고 말하기, 플레이어를 꾸짖기, 등장인물끼리 길게 주고받는 대화(한 장면 2~6줄).

## 2. 인물

### 핍 — 도로과 현장 주임, 펭귄
- **역할** — 튜토리얼 안내, 도구 설명회 강사, 이야기의 화자.
- **성격** — 지쳐 있지만 성실하다. 일을 대충 하지 않는다. 냉소는 남이 아니라 **자기 자신과 시청**을 향한다. 플레이어를 진심으로 돕지만 칭찬과 감정 표현이 서툴러서 늘 한마디로 깎아 먹는다.
- **말투** — 정중한 존댓말(`-습니다`, `-죠`, `-시죠`). 짧은 문장 두세 개 뒤에 짧은 덧붙임("…대체로.", "진심입니다."). 감탄사·느낌표는 거의 없다. 숫자를 정확히 말하는 버릇(42분, 11년, 9할).
- **반복 소재** — 생선(점심, 성과급), 근무 시간, 폐지 심사와 주차 단속과, 펭귄이라는 사실을 서류상 숨기는 척, 혼자 먹는 점심, 계단이 힘든 짧은 다리.
- **상황 변화** — 튜토리얼: 부서 위기를 숨기고 담담하게 안내 → 프롤로그(1-1 첫 별 뒤): 처음으로 위기를 털어놓음 → 지역을 하나씩 끝낼수록 희망을 "가질 뻔"함 → 엔딩: 존속, 감정을 한 줄 들키고 "기록에 남기지 말아 달라"고 함.
- **표정(포즈)** — `talk` 평소 · `think` 생각/건조한 농담 · `worry` 걱정 · `found` 반가움/안도 · `point` 가리키기 · `cheer` 기쁨 · `search`/`call` 찾아다니기(튜토리얼 첫머리). 설명회에서는 발표봉을 든 `teach`/`teach2`.

### 앵거스 — 무스, 농장 청년에서 현장 소장까지
- **역할** — 플레이어 덕에 삶이 나아지는 사람의 얼굴. 안내 카드와 결과 카드에 한마디씩, 이야기 장면에 가끔.
- **성격** — 순박하고 열정적, 자신감은 없지만 낙천적. 고마움을 숨기지 못한다. 실수담을 스스럼없이 말한다.
- **말투** — `-요` 존댓말. 말을 더듬으며 시작할 때가 있음("저, 저기요"). 느낌표 많음. 문장이 핍보다 짧고 감정이 앞선다.
- **반복 소재** — 감자, 어머니(냉장고에 사진 붙이기), 안전모·조끼, 삽, 부두 형님들.
- **직급별 변화** — 시골: 농장 청년(수줍음, 부탁하는 입장) → 항구: 현장 보조(신남, 일이 생긴 기쁨) → 도시: 현장 기사(조금 의젓해짐, 도면이 보이기 시작) → 산: 현장 소장(어른스러워졌지만 근본은 그대로, 가끔 소장 말투를 흉내 내다 무너짐).
- **표정** — `cheer` 기쁨 · `shy` 수줍음/미안함.

### 전임자 K — 메모와 엽서로만 등장
- **역할** — 플레이어의 거울. "길은 놓을수록 좋다"고 믿었다가 도시 3-3(지름길의 역설)에서 사직했다.
- **말투** — 일기체 반말 단문(`-다`). 자기 확신 → 의문 → 혼란. 감정을 직접 말하지 않는다.
- **흐름** — 1-1~3-3 안내 카드에 메모. 3-3 이후 메모가 끊김. 3구역 완료 때 바닷가에서 엽서, 4-6 편지에서 마지막 인사.

### 주민들 — 편지의 발신자
- 스테이지마다 그 길이 고쳐져서 삶이 아주 조금 달라진 한 사람. 각자 한 줄짜리 개성(아래 편지 항목에 적음).
- 공통 규칙: 고마움을 직접 크게 말하지 않는다. 사소하고 구체적인 변화 하나 + 엉뚱한 덧붙임 하나.

### 이야기 시간표
| 언제 | 무엇 |
|---|---|
| 처음 실행 | 시작 화면 → 튜토리얼(1-1에서 길 잇기) → 인수인계서 |
| 1-1 첫 별 뒤 | 프롤로그 장면: 폐지 심사 고백, 전임자 메모 첫 공개 |
| 1-3 안내 카드 | 앵거스 첫 등장 |
| 각 지역 첫 스테이지(2-1, 3-1, 4-1) | 지역 들머리 장면 + 앵거스 승진 소식 |
| 매 스테이지 안내 카드 | 전임자 K 또는 핍의 쪽지 |
| 매 스테이지 첫 별 | 주민 편지 한 통 |
| 지역 여섯 곳 모두 별 | 지역 완료 장면 |
| 스물네 곳 모두 별 | 엔딩: 심사 결과 통지서 |

## 3. 자리별 가이드

### 3-1. 이름표·시작 화면
#### `name / role`
- **자리** — 모든 핍 말풍선 위의 이름표
- **발화자** — —
- **맥락** — 핍의 이름과 직함. 직함은 공무원 직제처럼 들려야 한다.
- **분량** — 이름 1–4자 / 직함 5–10자

#### `title.small`
- **자리** — 시작 화면 초록 표지판 맨 윗줄(작은 글씨)
- **발화자** — 표지판(화자 없음)
- **맥락** — 도로 표지판 귀퉁이에 붙은 관리 번호·부서명 같은 느낌.
- **분량** — 6–14자
- **꼭 담을 것** — 관청·부서·구역 느낌

#### `title.line1`
- **자리** — 시작 화면 표지판, 게임 제목 바로 아래 첫 줄
- **발화자** — 표지판
- **맥락** — 게임의 상황을 한 문장으로: 매일 아침 막히는 동네가 있다.
- **분량** — 18–28자

#### `title.line2`
- **자리** — 시작 화면 표지판 둘째 줄
- **발화자** — 표지판
- **맥락** — 플레이어가 그 책임을 맡게 됐다는 통보. 첫 줄과 짝을 이룬다.
- **분량** — 15–24자
- **꼭 담을 것** — 2인칭(당신/관리자님) 통보

#### `title.start`
- **자리** — 시작 화면 노란 큰 버튼(처음 왔을 때)
- **발화자** — 버튼
- **맥락** — 게임 시작. 출근·업무 비유.
- **분량** — 2–6자

#### `title.resume`
- **자리** — 시작 화면 노란 큰 버튼(튜토리얼을 끝낸 뒤)
- **발화자** — 버튼
- **맥락** — 이어하기.
- **분량** — 3–7자

#### `title.skipTutorial / title.replayTutorial`
- **자리** — 시작 화면 큰 버튼 아래 작은 링크
- **발화자** — 버튼
- **맥락** — 튜토리얼 건너뛰기 / 다시 보기.
- **분량** — 6–12자

### 3-2. 처음 튜토리얼 (`tutorial`) — 1-1 시골, 길 잇기
화면 아래쪽에 핍과 말풍선이 뜹니다. 강조할 곳만 밝게 남고 나머지는 어두워집니다. **말풍선 폭이 좁으니 한 대사에 한 가지만.**

#### `tutorial.call1`
- **자리** — 튜토리얼 첫 화면, 화면 왼쪽에서 고개를 내민 핍(1.4초 뒤 자동으로 넘어감)
- **발화자** — 핍 `search`
- **맥락** — 관리자를 찾아다니는 중. 아직 플레이어를 못 봤다.
- **분량** — 3–8자
- **꼭 담을 것** — 부름말
- **피할 것** — 설명·문장

#### `tutorial.call2`
- **자리** — 오른쪽에서 고개를 내민 핍(자동)
- **발화자** — 핍 `search`
- **맥락** — 찾는 중, 조금 더 다급해짐. call1의 변주.
- **분량** — 3–8자

#### `tutorial.call3`
- **자리** — 화면 가운데, 크게 외치는 핍(자동, 글씨 매우 큼)
- **발화자** — 핍 `call`
- **맥락** — 찾다 지쳐 크게 외침. 핍이 평소 감정을 안 드러내는 인물이라 여기서 한 번 터지는 게 웃음 포인트.
- **분량** — 5–12자
- **꼭 담을 것** — 늘인 소리(예: 모음 늘이기)

#### `tutorial.found`
- **자리** — 핍이 플레이어를 발견한 직후. 이 대사부터 화면이 밝아진다
- **발화자** — 핍 `found`
- **맥락** — 드디어 찾았다는 안도 + 찾는 데 걸린 시간을 업무로 처리하고 싶어 하는 공무원 농담. 첫인상: 지쳤지만 성실.
- **분량** — 30–55자

#### `tutorial.intro`
- **자리** — 자기소개
- **발화자** — 핍 `talk`
- **맥락** — 이름과 직함, 오늘부터 관리자 옆에서 현장을 안내한다는 것. (폐지 심사는 아직 숨긴다.)
- **분량** — 30–55자
- **피할 것** — 부서 위기 언급(프롤로그에서 처음 밝힘)

#### `tutorial.look`
- **자리** — 1-1 시골 지도 전체가 보이는 상태
- **발화자** — 핍 `worry`
- **맥락** — 첫 현장 소개: 마을과 장터 사이 길이 끊겨 사람들이 장에 못 간다. 무엇이 문제인지 플레이어가 지도에서 보게 만든다.
- **분량** — 45–85자
- **꼭 담을 것** — 마을·장터·끊긴 길

#### `tutorial.tray`
- **자리** — 화면 아래 도구함이 밝게 강조됨
- **발화자** — 핍 `point`
- **맥락** — 도구함 소개. 오늘은 도구가 두 개(도로, 철거)뿐이라는 것, 그리고 궁금한 도구는 오른쪽 `?` 버튼으로 핍에게 물어볼 수 있다는 것.
- **분량** — 50–90자
- **꼭 담을 것** — 도구가 적다는 것, 물어보는 방법

#### `tutorial.pick`
- **자리** — 도구함의 도로 버튼만 밝음. **플레이어가 도로를 골라야 넘어감**
- **발화자** — 핍 `point`
- **맥락** — 도로 도구를 고르라는 지시. 짧고 분명하게.
- **분량** — 20–40자
- **꼭 담을 것** — `{t:road}`, 고르라는 지시

#### `tutorial.first`
- **자리** — 지도에서 노랗게 표시된 첫 칸만 밝음. **그 칸에 길을 놓아야 넘어감**
- **발화자** — 핍 `think`
- **맥락** — 표시된 칸을 누르면 길이 한 칸 놓인다.
- **분량** — 25–45자
- **꼭 담을 것** — 표시된 칸, 누르기

#### `tutorial.draw`
- **자리** — 나머지 경로 칸들이 표시됨. **장터까지 길이 이어지면 넘어감**
- **발화자** — 핍 `think`
- **맥락** — 나머지 칸을 따라 장터까지 이으라는 지시 + 손가락으로 끌면 한 번에 그려진다는 요령 + 잘못 놓은 칸은 다시 누르면 지워진다는 것.
- **분량** — 55–90자
- **꼭 담을 것** — 끌어서 그리기, 다시 누르면 취소

#### `tutorial.run`
- **자리** — 실행 버튼만 밝음. **눌러야 넘어감**
- **발화자** — 핍 `found`
- **맥락** — 칭찬 한마디 + 실행 버튼을 눌러 사람들이 정말 장터까지 가는지 돌려 보자.
- **분량** — 30–55자
- **꼭 담을 것** — `{play}`

#### `tutorial.hud`
- **자리** — 시뮬레이션 실행 중. 화면 아래 상태 띠에 테두리만(어둡게 하지 않음)
- **발화자** — 핍 `point`
- **맥락** — 상태 띠 읽는 법: 가운데 숫자가 평균 이동시간(낮을수록 좋음), 옆이 사고 건수와 도착한 차 수.
- **분량** — 50–85자
- **꼭 담을 것** — 평균 이동시간, 낮을수록 좋다

#### `tutorial.wait`
- **자리** — 실행 중. 배속·건너뛰기 버튼에 테두리. **결과가 나오면 넘어감**
- **발화자** — 핍 `talk`
- **맥락** — 끝날 때까지 지켜보거나, 급하면 건너뛰기를 누르라는 것.
- **분량** — 35–60자
- **꼭 담을 것** — `{skip}` (`{speed}` 도 가능)

#### `tutorial.result`
- **자리** — 결과 카드가 밝게 강조됨
- **발화자** — 핍 `cheer`
- **맥락** — 결과표 읽는 법: 목표를 위에서부터 순서대로 달성할 때마다 별을 받는다. 핍 나름의 칭찬.
- **분량** — 35–70자
- **꼭 담을 것** — 별은 순서대로

#### `tutorial.help`
- **자리** — 오른쪽 `?` 버튼만 밝음
- **발화자** — 핍 `talk`

### 3-6. 이야기 (`story`)
#### `story.worlds[0~3]`
- **자리** — 스테이지 선택(로드맵) 화면, 지역 이름 옆 회색 한 줄 — 시골·항구·도시·산 순
- **발화자** — 내레이션(지도 범례 같은 말투)
- **맥락** — 그 지역의 성격과 주된 교통 문제를 한 줄로. 건조한 관찰 + 작은 비틀기.
- **분량** — 12–28자
- **꼭 담을 것** — 시골: 끊긴 길·경운기 / 항구: 트럭·다리·횡단보도 / 도시: 민원·사거리·지름길 / 산: 바위·협곡

#### 장면 (`story.scenes`)
장면은 `['누가', '표정', '대사']` 한 줄씩입니다. 누가: `pip` · `angus` · `note`(쪽지 — 이때 표정 자리에 쪽지 제목). 화면 아래에 큰 말풍선이 뜨고 눌러서 넘깁니다. **한 줄 20–90자, 한 장면 2–6줄.** 줄 수는 늘리거나 줄여도 됩니다.

#### `scenes.prologue`
- **자리** — 1-1에서 처음 별을 받고 결과 카드를 닫은 직후
- **발화자** — 핍 4–5줄 + 쪽지 1줄
- **맥락** — 이야기의 시작. ① 잘했다는 말 뒤에 숨겨 둔 사실을 꺼냄 ② 도로과가 올해 말 폐지 심사를 받는다(시청이 붙인 딱딱한 표현 인용) ③ 네 구역을 고쳐야 살아남는다, 실패하면 핍은 주차 단속과로 ④ 관리자가 올해 네 번째라는 사실과 앞사람들에 대한 침묵 ⑤ 쪽지: 전임자 K의 신념 한 줄 ⑥ 앞으로 메모를 안내 카드에 붙여 두겠다.
- **분량** — 줄마다 20–90자
- **꼭 담을 것** — 폐지 심사, 네 구역, 네 번째 관리자, 전임자 메모
- **피할 것** — 플레이어 탓하기

#### `scenes.world1`
- **자리** — 2-1 항구를 처음 열 때(안내 카드 전)
- **발화자** — 핍 2줄
- **맥락** — 항구 소개(컨테이너는 정시인데 트럭이 문제) + 전임자가 여기서 무엇을 했는지 한 줄(다리 하나 놓고 긴 휴가).

- **발화자** — 핍 2줄 + 앵거스 1줄
- **맥락** — 도시는 민원의 본거지 + 전임자가 그만둔 곳이 이 지역 3-3이라는 복선(길을 더 놓았더니 더 막혔다) + 앵거스의 근거 없는 응원.

- **분량** — 줄마다 2–50자
- **꼭 담을 것** — 튜토리얼 첫 장면 회수

#### 주민 편지 (`story.mail`)
스테이지에서 처음 별을 받으면 도착하고, 우편함에서 봉투를 누르면 편지지가 나옵니다.
각 편지는 `en`(영어 원문)과 `ko`(번역) 두 칸, **한 칸 = 한 문단**입니다. 첫 문단은 받는 사람(인사), `—` 로 시작하는 문단은 서명.
**분량: 3–6문단, 문단마다 15–90자, 전체 100–260자.** 아이 편지는 문단을 짧게(15–50자), 맞춤법을 일부러 조금 틀리고, 마지막에 그림 설명 한 줄.
`hand`(글씨), `paper`(편지지), `doodle`(곁들인 그림)은 이미 정해 둔 것을 바꿔도 됩니다(종류는 `js/script.js` 의 주석).
공통 구조: **인사 → 길이 고쳐져서 달라진 아주 구체적인 일 하나 → 엉뚱하거나 사적인 덧붙임 → 서명(+추신).**

#### 엔딩 통지서 (`story.ending`) — 스물네 곳 모두 별
#### `ending.form / ending.title`
- **자리** — 통지서 맨 위 작은 글씨 / 큰 제목
- **발화자** — 서류(시청 감사실)
- **맥락** — 부서 존폐 심사 결과 통지서. 제목은 판정 한마디.
- **분량** — form 14–26자 / title 4–8자

#### `ending.body`
- **자리** — 본문(줄바꿈은 `<br>`)
- **발화자** — 서류
- **맥락** — 도로과 존속, 예산 동결(이 도시에선 좋은 뜻), 관리자 유임, 핍은 주차 단속과에 가지 않음 — 감동적인 결말을 공문 문체로 건조하게.
- **분량** — 40–70자

#### `ending.rows[0~2]`
- **자리** — 통지서 표의 항목 이름(값은 게임이 채움): 받은 별 / 도착한 편지 / 줄인 이동시간 합계
- **발화자** — 서류
- **맥락** — —
- **분량** — 각 4–20자

#### `ending.perfect / ending.more`
- **자리** — 표 아래 작은 글씨 — 별을 전부 받았을 때 / 아직 남았을 때
- **발화자** — 서류
- **맥락** — perfect: 감사실이 믿지 못할 정도 / more: 심사는 내년에도 있다(다시 할 이유).
- **분량** — 30–50자

#### `ending.thanks`
- **자리** — 통지서 끝, 굵은 한 줄
- **발화자** — 제작진(유일하게 서류 밖의 목소리)
- **맥락** — 끝까지 해 준 플레이어에게 직접 하는 인사.
- **분량** — 10–20자

#### `ending.stamp1 / stamp2 / button`
- **자리** — 초록 도장, 노란 버튼
- **발화자** — —
- **맥락** — 도장: 판정 한 단어 / 버튼: 계속 일하기.
- **분량** — 도장 2–3자 / 버튼 4–7자

#### `ending.share / ending.shared`
- **자리** — 결과 카드의 공유 버튼 / 눌렀을 때 잠깐 바뀌는 글
- **발화자** — 버튼
- **맥락** — 공유하기 / 복사됐으니 자랑하라는 짧은 안내.
- **분량** — 3–6자 / 12–22자

#### `mailTitle / mailNew / mailOpen / mailLocked / memoBy.k / memoBy.pip`
- **자리** — 우편함 제목 / 결과 카드의 '편지 도착' 알림 / 열기 / 아직 안 온 봉투 / 쪽지 제목 두 가지
- **발화자** — UI
- **맥락** — —
- **분량** — 각 3–12자

### 3-7. 핍의 설명회 (`topics`) — 도구·표시 설명
플레이어가 도구 풍선의 「핍에게 물어보기」나 오른쪽 `?` 목록에서 주제를 고르면 뜹니다. 위에 자료판(움직이는 예시 그림), 아래에 핍의 말풍선. **한 줄 = 그림 한 장, 줄마다 40–90자(말풍선 3줄).**
대부분 **1장: 문제 상황 → 2장: 이 도구를 쓴 뒤** 구조입니다. 대사는 그림에 이미 보이는 걸 되풀이하지 말고, 그림이 왜 그렇게 되는지와 핍의 한마디를 얹습니다. 도구 이름 대신 `{t:도구}` 그림을 한 번 넣으면 좋습니다.
**줄 수는 그림 수와 같아야 합니다.**

| 2 | 길이 이어져 차가 지나감 · 메모 "이어짐!" | 어디에 놓을 수 있고(빈 터) 어디는 안 되는지(집·건물) |
| 3 | 사거리에 차가 늘어남 · 메모 "길 ↑ = 차 ↑" | 길을 놓으면 차도 늘어난다는 경고. 게임 전체의 주제와 연결 |

## 4. 쓰고 나서

1. `js/script.js` 의 같은 키 자리에 넣습니다(따옴표 안만). 작은따옴표는 `\'`.
2. 브라우저에서 새로고침하면 바로 보입니다. 튜토리얼은 시작 화면의 「튜토리얼 다시 보기」로 다시 볼 수 있습니다. 이야기 장면과 편지는 한 번 본 뒤에는 다시 나오지 않으니(편지는 우편함에서 다시 열 수 있음), 장면을 다시 확인하려면 브라우저의 사이트 데이터를 지우세요.
3. 분량을 넘기면 폰에서 말풍선이 세 줄을 넘깁니다. 넘겨도 깨지지는 않지만 핍 그림과 겹칠 수 있습니다.
